# Little Hours — ChatGPT guest preview

Play: https://rexliao0830-sketch.github.io/little-hours-chatgpt-preview/

This repository contains only the built website. Editable source and the maintainer handoff are on the `chatgpt` branch of `rexliao0830-sketch/little-hours`. The original `main` branch is preserved.

Source revision: `a53df76b56cce4cce0523643aba37c296a132060`

Choose **Try without an account**. Existing guest progress stays in this browser.

- **Study Dome**: Plan a task, start a linked timer, save an outcome and next step, review/export records, import/export supported calendars, and open music.
- **Study Rooms**: Try a local group with shared goals, tasks, chat, a separate shared garden and break games. Capacity settings support up to 30 members and up to 10 builders in the account implementation.
- **Star Arcade**: Short memory/constellation games with a shared daily allowance; no game currency farming.
- **Workshop**: Optional personal avatar, colours/accessories, home artwork, themes and data export.
- **My Garden**: The prior living town, kits, interiors, expandable land, walking and construction remain available.

The world dock switches between overhead and first person. WASD moves; right-drag looks; E interacts; F places; R rotates.

This build deliberately enables the local guest preview. It does not connect real remote participants or provision video calls. Online group synchronization, account-backed rewards/building and Daily meetings need a **separate ChatGPT Supabase project** and provider configuration; the original Claude database is untouched. The private source contains the migrations, edge function, tests, research/coverage ledger and maintainer instructions. No live account/provider deployment is claimed.
